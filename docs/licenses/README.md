These are the license texts for the separately distributed FFmpeg executable.
The minimal macOS build uses LGPL 2.1 or later. The upstream Windows LGPL build
uses LGPL 3 or later. LGPL 3 incorporates GPL 3 text, so both texts are supplied;
including that text does not turn the LGPL executable or Mob Boss into a GPL build.
See the top-level THIRD-PARTY-NOTICES.md for exact versions, source archives,
checksums and build instructions.
