# Mob Boss logo concepts

Open [preview.html](preview.html) at 100% browser zoom, or view [preview.png](preview.png) at native resolution. Each concept appears in the existing header styling in both themes, with a 28 px mark and a 4× brand detail. The detail crops the header and hides its subtitle. Header controls are illustrative and inert.

1. **Media stack** — Three ordered media cards bring scattered media into one place. App icon: yes; strong square silhouette with padding. **Recommended** for the quietest, most direct media-management reference.
2. **Mob links** — Three linked objects express a clip’s relationships to its media. App icon: viable, but the open silhouette is less distinctive in a crowded dock.
3. **Bin B** — A media-bin spine and two compartments form a restrained B for Boss. App icon: yes; strongest single silhouette, with a background added later.

All artwork is original, drawn from basic geometry, with no third-party artwork or Avid logo references. SVGs have a 24-unit viewBox and use only currentColor. Designed for 24–32 px; the preview uses 28 px. Inline the chosen SVG inside an element colored with var(--accent); an external img will not inherit the parent color. Dark accent: #6aa8ff. Light accent: #1f5fd1.

Proposal assets only. Header code remains unchanged pending Brandon’s choice.
